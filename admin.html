제미나이(생산 & 가상OS 테스트) → Argon(외관 표준) → GPT Think(추론 검증) → Git(자동 운영) 파이프라인이 어떻게 돌아가고 어디서 확인하면 되는지 한눈에 점검하는 페이지입니다.

1단계 · 생산 (Gemini)
가상 OS 실습 2회 + 사이트 발전 1회
오전 9시·오후 3시에는 가상 OS에서 PC 이름 변경·클릭 등을 테스트해 글을 쓰고, 새벽 3시에는 블로그 외관을 1회 발전시킵니다.
2단계 · 외관 (Argon Only)
Argon 디자인 시스템 고정
인디고(#5e72e4)·민트(#2dce89) 팔레트와 글자 확대 돋보기, OS 창 액자 등 Argon 규격으로만 일관되게 렌더링합니다.
3단계 · 검증 (GPT Think)
다단계 추론 품질 게이트
컴맹 눈높이 친절도, 가상 OS 캡처 3장 무결성, Argon 레이아웃 정상 여부를 추론 검증하여 승인(APPROVED) 판정을 내립니다.
4단계 · 운영 (Git & Pages)
검증 통과분 자동 커밋·배포
검증을 통과한 파일만 Git 저장소에 푸시되어 블로그에 자동 반영되며, 모든 증적은 _data/와 이 페이지에 기록됩니다.

📍 내가 어디서 무엇을 확인하면 되나요? (5대 핵심 점검 포인트)

점검 항목 확인하는 곳 (경로 / 위치) 무엇을 보면 되나요?
1. 하루 3번 자동 실행 여부
(포스팅 2회 + 사이트 발전 1회)		 GitHub 저장소 상단 [Actions] 탭 → Argon Blog — Gemini Producer... 초록색 체크(✅) 표시와 함께 새벽 3시(사이트 발전), 오전 9시·오후 3시(포스팅) 실행 로그 확인
2. 제미나이 가상 OS 테스트 결과 저장소 내 audit_logs/last_os_test.json 및 assets/images/날짜/ 폴더 virtual_display_status: PASS 여부와 1~3단계 가상 OS 캡처 이미지 3장 생성 확인
3. GPT Think 추론 검증 리포트 각 포스트 맨 아래 [🛡️ GPT Think 검증 완료 박스] 또는 아래 실시간 로그 패널 검증 점수(Score: 100/100), APPROVED 판정, 3줄 추론 심사평 확인
4. 하루 1회 Argon 외관 발전 내역 저장소 내 _data/evolution_history.json 및 아래 우측 패널 매일 어떤 Argon 초보자 편의 기능(돋보기, 용어사전, 체크박스 등)이 추가되었는지 버전별 확인
5. 다음 수업 주제 추가·순서 변경 저장소 내 curriculum.json 및 posted_history.txt 이미 발행된 수업 ID는 posted_history.txt에 기록되며, 새 주제는 curriculum.json에 추가
