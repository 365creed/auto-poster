# 🏫 ChooSu Note — 세상에서 가장 친절한 컴퓨터 기초 학교 & 가상 OS 실험실

아무것도 모르는 입문자도 고개를 끄덕이며 **"아! 이게 클릭이구나!"** 하고 이해할 수 있도록, 컴퓨터·노트북의 역사부터 운영체제(OS) 기초 조작까지 **가상화 OS 환경에서 AI가 직접 조작하고 미니게임을 플레이하며 찍은 스크린샷**으로 설명하는 하이브리드 블로그입니다.

## ⏰ 하루 3번 하이브리드 운영 구조 (자동 2회 + 수동 1회)

| 시간대 (한국 시간 KST) | 운영 방식 | 교시 및 콘텐츠 성격 |
| :--- | :--- | :--- |
| **☀️ 오전 09:00** (`0 0 * * *` UTC) | **AI 자동 연산 (1회차)** | **1~3교시 기초 원리**: 컴퓨터·노트북의 역사, 0과 1 이진법, 마우스 클릭, 창(Window)과 폴더 개념 |
| **🎮 오후 15:00** (`0 6 * * *` UTC) | **AI 자동 연산 (2회차)** | **4교시 가상 OS·게임 실습**: AI가 가상 OS에서 직접 지뢰찾기·타자연습·탐색기를 플레이하고 3단계 캡처 |
| **🌙 저녁 시간** | **인간 에디터 수동 발행** | **방과후 보충 노트**: 사람이 직접 겪은 경험담, 초보자 Q&A, 따뜻한 수동 에세이 발행 |

## 🌙 저녁 수동 포스팅 올리는 3가지 방법

1. **블로그 내 웹 스튜디오 (`/auto-poster/studio.html`) 활용**
   - 블로그 우측 상단 **[🌙 저녁 수동 포스팅 스튜디오]** 버튼을 눌러 제목·본문을 작성한 뒤 마크다운(`.md`) 파일을 다운로드하여 `_posts/`에 추가합니다.
2. **GitHub Actions 웹 수동 실행 (`workflow_dispatch`)**
   - GitHub 저장소의 **Actions** 탭 &rarr; `ChooSu Computer School — Hybrid Auto & Manual Publisher` &rarr; **Run workflow** 클릭 후 제목, 주제, 직접 쓴 본문, 가상 OS 캡처 모드를 선택해 실행하면 가상 OS 스크린샷이 자동 첨부되어 발행됩니다.
3. **터미널 CLI 명령어 (`manual_post.py`)**
   ```bash
   python manual_post.py --title "처음 노트북을 샀을 때 꼭 해볼 마우스 설정" --topic "커서 속도 조절하기" --scene click_trainer
   ```
